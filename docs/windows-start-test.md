# Windows 单页开始测试

2026-10-23。当前只联调 Windows 调试版，不制作安装包。

启动后默认进入“开始测试”。材料、抽样和显示设置都在这一页，不需要切换草稿、发布或版本。

1. **选择测试素材。**点击目录输入框右侧文件夹按钮，选四个 `*_renders` 的共同上一级目录，自动读取。也可粘贴路径后点击“读取目录”。标准素材可以选择含 `study.json` 的源目录，左右眼文件位置任意，用描述文件明确引用。
2. **设置每人抽取数量。**每个分组旁显示全部候选数量，填写本次每位参与者抽取的图片对数，范围 1～候选数量。原四序列共 5,000 对，默认 VRU 各 4 对、Dance/Show 各 6 对。每对默认判断两次、先后次序平衡，因此默认每人 20 对、40 次判断。每人独立抽样，恢复保持原抽样。
3. **设置显示。**Patch 可开关，像素宽、高独立填写；3D 可开关，默认 Full SBS。没有完整右眼引用时，页面解释原因并禁止以 3D 开始，不能拿两个视点自动冒充双眼。鼠标与双眼 UI、图片阶段隐藏鼠标等原规则继续生效。
4. **核对“本次测试参数”。**同页列出候选池大小、每人图片对数和判断次数、2D/3D、Patch 尺寸、提示和图片时长、演练标记与作答问题。修改目录后，必须读取成功才能开始，避免输入了新目录却使用旧池。
5. **点击“登记参与者并开始测试”。**填写匿名编号及观看条件，确认即进入测试。取消登记不生成会话或新版本。开始前会检查抽中的原图，错误显示在本页；不复制素材。
6. **继续或换人。**退出测试返回本页。未完成会话列在下方，每条显示其原来的显示模式、Patch 和进度，直接点击“恢复测试”。同一素材的不同参数会话也会列出，恢复不会覆盖上方准备的新参数。下一位填写新编号。

软件会记住上次读取的素材和成功开始时使用的设置。不同设置自动留存独立版本，相同设置和素材绑定重复开始复用已有版本。这些记录用于结果追溯，普通流程不要求手动发布。旧会话不会被新设置改写；改变素材目录绑定也不会覆盖旧版本的原目录。

当某个分组只抽 1 对且判断两次时，该分组的两次判断会相邻；默认每组抽多对时保持原不相邻约束。真实感正式模板的额外约束继续校验，不会自动取消。

修改题目、分析规则、独立练习/控制材料，或使用旧包和高级编辑时，仍可进入“高级实验管理”。原采集会话、结果汇总、导出与旧格式入口继续保留。

## 验证

`test/quick_test_test.dart` 验证范围与显示参数、每组一对、3D 缺眼阻止、不同尺寸窗口、自动配置复用、新旧参数隔离和标准双眼源反复读取。`integration_test/quick_test_test.dart` 直接从原四序列加载 5,000 对：

- 在首页填写每组 1 对和 Patch 512×320，确认 8 次判断。
- 取消登记不创建空版本；完成第一位模拟参与者 8 次作答，中断后从同页恢复。
- 第二位使用相同参数，复用配置、独立随机抽样。
- 修改为每组 2 对和 Patch 640×360，新会话有 16 次判断，旧会话保持 512×320。
- 从同页恢复旧 512×320 会话后，新建参数仍为 640×360。

证据保存在忽略跟踪的 `validation/quick-start-windows/`，原生流程使用 30 ms 测试计时，模拟数据不进入用户采集库。软件正常运行读取配置中的 2 秒提示 / 3 秒图像。旧入口原生回归证据在 `validation/quick-start-legacy-windows/`。

最终回归：60 项 Flutter 测试通过，静态分析无问题。新单页原生流程约 33 秒，验证 5,000 对池、相同配置复用、8/16 次判断切换及旧参数恢复；旧原生回归约 41 秒，包含真实默认计时、完整 46 次旧版判断和通用 v2 采集。未运行发布构建或制作安装包。
