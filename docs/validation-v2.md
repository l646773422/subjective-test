# v2 平台验证记录

日期：2026-10-16。使用合成演示素材验证软件行为，不构成正式主观评价结论。

本页为 2026-10-16 的历史验证，包含当时的 Android 和 Release 记录。2026-10-23 的素材池验证见 [Windows 真实素材流程](real-materials-workflow.md)，双眼与 Patch 验证见 [双眼与 Patch](stereo-and-patch.md)。当前只联调 Windows，不重新打包发布。

## 实现范围

- schema 2 标准目录、源 ZIP 和发布 ZIP 导入；草稿持久化、配置、题目编辑和顺序预览。
- 发布时展开默认值，冻结图片与定义，记录 SHA-256、宽高、执行版本和独立 revisionId。
- 任意题量、不同图片尺寸、可选练习/控制/标准答案、随机或平衡次序、分组与重复。
- 动态登记字段与参与条件，选择比例和准确率分析，真实感模板的独立判定。
- v2 答案同时记录素材身份与实际位置；版本内结果导入幂等、冲突检测和 CSV / JSON 导出。
- schema 1 包与会话继续使用原排程、序列条件、控制题和统计实现，旧文件不原地迁移。

## 自动检查

40 项 Flutter 单元 / 界面测试通过，13 项 Python 合同 / 转换测试通过。静态分析完成后无问题。

新增覆盖包括最小单题输入、任意子目录与中文路径、不同图片尺寸、零提示时长、可选控制与标准答案、150 个种子的次序平衡与不相邻约束、跨设备发布包往返、定义替换拒绝、跨版本结果隔离、坏文件隔离、手机布局、草稿自动保存与通用登记。

`test/fixtures/legacy-session.json` 来自原 Windows 验证归档，保留真实排程、答案和部分呈现事件，验证 schema 1 反序列化往返、固定种子排程与四序列 50% 汇总不变。v2 排程以独立生成的 seed 117 预期序列固定行为；Python / Dart 共享 `v2-expanded.json` 校验默认值，避免两种入口产生不同配置。

## 原生场景

Windows x64 和 Android 36 x86_64 测试模拟器各通过三项场景：

1. 按默认真实 2 秒提示 / 3 秒图像完成一题呈现，答题停留超过 6 秒仍等待；暂停后落盘且不产生答案。
2. 通过真实管理界面载入旧演示包、登记、完成原 46 次判断，复核控制题、持久化、统计、导出和重复导入。
3. 通过通用界面完成 v2 单题实验，不要求练习、控制、年龄或专家信息；验证第二幅选择对应的素材身份，发布包在另一存储目录导入，结果合并幂等。

后两项只在测试构造器中注入 30 ms 阶段时长；生产入口无该覆盖。没有声称完整 46 题和 v2 流程都按默认真实时长运行。

## 证据与复现

命令见 README。完整证据保存在忽略跟踪的 `validation/v2-windows/`、`validation/v2-android/`：`report.json` 包含 timing、旧版 results、v2Results；PNG 包括旧版准备/呈现/作答/结果及 v2 实验库、作答和结果。

Android 验证使用既有 AVD 的独立只读实例 `emulator-5580`。未向连接的实体设备安装应用或清理数据。首次系统全屏提示需确认；测试等待横屏布局稳定后再点击，保留原真实计时断言。

## 发布与限制

Windows x64 Release、Android ARM64 / x86_64 Release 构建通过，版本为 0.2.0+2。已检查两端包中的通用演示资源，以及 APK 中的两种原生架构。APK 在测试模拟器中覆盖安装并冷启动成功，进程存活，未发现 Flutter 未处理异常。本地 dist 产物和 SHA-256 清单已更新。

Release 产物沿用原应用 ID、可执行文件名和数据根目录，Android 保留当前内部调试签名。源素材读取能力仅支持静态 PNG / JPEG；正式屏幕、观看距离、亮度、颜色与实际实验素材仍需组织者按方案联调。

v1 统计合同不随通用化放宽。v2 基础指标只提供描述性统计，只有明确启用真实感 profile 的版本才采用该方案的判定规则。
