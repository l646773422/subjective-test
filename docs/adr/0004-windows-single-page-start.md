# ADR 0004 Windows 单页开始测试

状态：已实施。日期：2026-10-23。

用户要求把选素材目录、每组抽样数量、Patch、3D 和开始测试放在同一页，明确当前参数，移除普通操作中的手动草稿与发布切换。

## 决策

1. Windows 首页为“开始测试”，旧实验库归入“高级实验管理”。原 Android 入口不接入新流程，本轮不构建或发布安装包。
2. 读取原始 renders 素材池或标准 study.json 源目录，建立本地独立素材绑定；参数编辑保留在当前页面，跨页查看记录时保持。记住上次选择的素材与成功开始时的设置。
3. 点击开始先读取本页参数快照并登记参与者，取消不建立会话或版本。确认后自动生成或复用完整定义与素材绑定相同的不可变版本，再抽样、固定指纹、保存会话并进入呈现。普通 UI 不要求操作者管理 revisionId。
4. 保留已有发布合同、调度版本和结果归属。新设置不会修改旧会话；复用配置时必须比较素材绑定，以免将旧会话重新指向另一目录。旧会话按其原版本恢复，同页列出该素材不同参数下的未完成会话。
5. 输入目录变化但尚未读取、超出候选数、缺少右眼或像素配置无效时，阻止开始并显示具体原因。源图尺寸和实际内容在既有发布/所选素材校验中检查，失败不显示半对图像。
6. 每组只抽一对时，流程演练允许连续的平衡重复，撤掉不可实现的不相邻要求；正式模板约束不自动放宽。现有默认每组多对不变。

此方案复用既有执行和存储规范，避免引入另一套结果格式。代价是修改配置仍会在内部增加版本记录；界面隐藏普通操作不需要处理的版本步骤，高级管理和审计能力保留。

验证和操作见 [Windows 单页说明](../windows-start-test.md)。
